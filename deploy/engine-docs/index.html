Engine principles

A hard boundary around game truth

The engine is designed for long-running 4X worlds where every decision, hidden fact, replay, and platform boundary must remain trustworthy.

01

Deterministic

Explicit inputs, fixed-point values, stable ordering, bounded work, and exact replay evidence.

02

Framework-free

The pure crates depend on no UI, filesystem, network, database, wall clock, Flutter, or Godot.

03

Recipient-safe

Clients receive projected snapshots and patches, never hidden canonical state reconstructed remotely.

04

Parity-led

Behavior moves as complete vertical slices backed by reviewed fixtures and fail-closed gates.
