One engine, two clients, one online host

Rust owns canonical state, rules, deterministic transitions, AI, save, replay, and recipient projection. Flutter/Flame and Godot render the same client contract; Serverpod owns authenticated durable transport.

Content & contracts

Strict maps, scenarios, catalogs, canonical DTOs, and explicit protocol identities.

Engine

Commands, queries, turn processing, evidence, outcome, AI, persistence, and replay.

Projection & runtime

Recipient-safe views, transactional local sessions, snapshots, patches, and stateless server calls.

Hosts

Flutter/Flame, Godot/Terrain3D, and Serverpod consume narrow native boundaries without owning rules.

Fail-closed boundaries

Rejections never mutate committed state. A session retains one build, contract, and content identity. Hidden canonical state never crosses a recipient boundary. Versions exist only for real durable or independently deployed consumers.
